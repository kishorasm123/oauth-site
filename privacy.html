Privacy Policy

Last updated: 22 October 2026

This policy applies to the personal automation application n8n Gmail Assistant, operated solely for the account owner's personal use.

Data accessed

  • Email messages in the owner's own Gmail account (subject, sender, body, attachments) — read via the Gmail API scope gmail.modify.
  • No data is collected from any other person or account.

How data is used

  • Classifying and organizing the owner's own email (keep / trash / label).
  • Generating a daily summary digest sent to the owner's own Gmail address.
  • Summarizing text extracted from PDF attachments in the owner's own email.

Storage & sharing

  • All processing happens on the owner's own self-hosted server (Raspberry Pi) on a private network.
  • Email content is never sold, shared, or used for advertising.
  • Text may be sent to a third-party AI API solely to produce summaries of the owner's own documents; no account data is retained by that service beyond the request.

Your rights

Because this is a single-user personal app, the owner has full control: revoke API access at any time via Google Account → Security → Third-party access, or delete the OAuth client in Google Cloud Console.
